# AGENTS.md - Project conventions for AI assistants

## Commit message format
type: short description

Types: feat, fix, refactor, docs, chore, test, perf, style
- feat: new feature or experiment
- fix: bug fix
- refactor: code restructuring
- docs: documentation only (README, RUN_TRACKING)
- chore: tooling, config, gitignore, etc.
- perf: performance improvement

## Project structure
- model.py: CNN model definition
- train.py: training pipeline
- aie231assgnmnt3.ipynb: main Jupyter notebook (Colab)
- RUN_TRACKING.md: experiment log

## Commit frequency
Commit after every meaningful change. Push after every 1-3 commits.
